# Alpha 5: Ruf aus realer Nachfrage

Die frühere Bestandsbewegung ist keine Rufquelle mehr. Nur tatsächlich ausgeführte Spielerverkäufe an gedeckte Stadt- oder Bevölkerung-Buy-Orders erhöhen lokalen Ruf. Die konfigurierten Mengenregeln bleiben erhalten; jeder Execution-Beleg erhöht Ruf höchstens einmal.
