# Alpha 5: Geldbilanz-Abnahme

Jeder Befehl und jeder Tick prüft die konstante Geldmenge von `170.717.000 moneyUnits`, nichtnegative Konten und die Kontogleichung `availableMoney + reservedMoney = totalAccountMoney`. Jede erfolgreiche Goldbewegung besitzt ausgeglichene Ledger-Einträge; ein Rollback hinterlässt weder Buchung noch Ledger-Rest.

Die vollständige Alpha-5-Abnahme einschließlich Orderbuch, Migration, Bevölkerung und mobiler Oberfläche wird in der gleichnamigen Testwelt- und Abnahmekonzeption ergänzt.
