# Alpha 5: Startzustand

Die Alpha-5-Basiswelt startet ausschließlich mit den sieben Konten und Geldbeträgen aus [`money-and-ledger.md`](money-and-ledger.md). Ihre Gesamtgeldmenge ist exakt `170.717.000 moneyUnits`. Reservierungen starten bei null und sind kein zusätzliches Geld.

Die Migration multipliziert bisherige ganzzahlige Goldstände exakt mit 100 und ordnet jede bisher verschwindende Gebühr einer Stadtkasse zu. Stadt- und Bevölkerungskassen werden nur durch die Weltinitialisierung angelegt; es gibt kein neutrales oder unbegrenztes Goldkonto.
