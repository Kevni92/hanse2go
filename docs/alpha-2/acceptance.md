# Alpha 2 – Abnahme

Der reale Client und Server prüfen mobil und Desktop: Rufaufbau, Konzession, Kontorzwang, Material- und Goldfehler, Flottenlagerung, Rohstoff- und Verarbeitungsbau, Stillstand, Tickproduktion, Verbrauch und Tickbericht. Daten-/API-Tests decken alle Katalogrezepte ab. Negative Tests decken fehlenden Ruf, Gold, Material, Konzession, Kontor, Inputs, Laderaum und Tick-Doppelklick ab; Reset ist nur im Testbetrieb verfügbar.
